## 💻 System Requirements

NovOS works on most modern hardware. Ensure your computer meets these minimum specifications for the best experience:

* Operating System: Windows 10 or Windows 11.
* Memory: 4 gigabytes of RAM or more.
* Storage: 200 megabytes of free space on your hard drive.

## 🚀 Key Features

NovOS brings several tools to your screen. These features improve how you interact with your browser:

* Window Management: Open, move, and resize multiple apps at the same time. The interface uses a familiar layout that feels like a standard desktop.
* Nova AI: Access an intelligent assistant directly on your desktop. This tool helps you search for information or perform tasks without leaving the NovOS environment.
* File Storage: Save your workspace data locally using IndexedDB. Your settings and files remain available when you return to the app.
* POSIX Compatibility: NovOS follows standard operating system design patterns. This structure keeps your folders and settings organized in a logical way.
* Responsive Design: The interface adjusts to fit your monitor size. It maintains a clean look regardless of how many windows you open.

## 💬 Frequently Asked Questions

**Does this replace my Windows installation?**
No. NovOS runs as an application on top of Windows. It does not change your existing files or system settings.

**How do I save my work?**
The system saves data automatically as you work. You do not need to hunt for a save button.

**Where does my information go?**
Your data stays on your local computer via your browser storage. NovOS respects your privacy by keeping information local unless you choose to use the cloud or AI features.

**Can I run other software in NovOS?**
NovOS supports built-in applications designed for the platform. You cannot install standard Windows programs directly into NovOS at this time.

**What happens if the app freezes?**
Refresh your browser tab or close the window and open it again. The app remembers your last session.
